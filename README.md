# RDH-2DHIST-BP — Reversible Data Hiding With Brightness Preserving CE by 2D Histogram Modification

> **Paper:** Wu H-T., Cao X., Jia R., Cheung Y-M., *"Reversible Data Hiding With Brightness Preserving Contrast Enhancement by Two-Dimensional Histogram Modification"*, IEEE Trans. Circuits Syst. Video Technol., Vol. 32, No. 11, pp. 7605–7617, Nov. 2022. DOI: [10.1109/TCSVT.2022.3180007](https://doi.org/10.1109/TCSVT.2022.3180007)

---

## Novelty

Combines **2D histogram modification** (finer brightness control than 1D) with **brightness preservation (BP)** for reversible CE-RDH. Prior work ([21] Wu 2019) used 2D hist without BP; prior BP work ([22] Kim 2019) used 1D hist. This paper is the first to combine both.

---

## Algorithm

```
For each iteration (up to n=80):
  1. Build 2D histogram H from non-overlapping pixel pairs (i,j)
  2. Compute brightnessL (left pixels) and brightnessR (right pixels)
  3. BP direction choice:
       brightnessL > orig → LHS (reduces L); else → RHS (increases L)
       brightnessR > orig → DHS (reduces R); else → UHS (increases R)
  4. Choose H vs V based on which gives more embedding capacity
  5. Apply chosen direction (Eq. 3–7): merge min column/row, expand max
  6. Embed bits at peak column/row
  7. Store side info: 17 bits (p/q 8b + r/s 8b + dir 1b) + location map
  8. Stop when pure capacity ≤ 34 bits
Recovery: reverse iterations in reverse order (Eq. 8–13)
Color: apply R, G, B independently
```

### 4 Directions

| Dir | Axis | Effect on Brightness |
|-----|------|---------------------|
| LHS | Left pixel (col p→p-be) | Decreases brightnessL |
| RHS | Left pixel (col p→p+be) | Increases brightnessL |
| DHS | Right pixel (row q→q-be) | Decreases brightnessR |
| UHS | Right pixel (row q→q+be) | Increases brightnessR |

## Results (n=80)

| Image Set | RCE | PSNR | SSIM | BD (brightness diff) | bpp |
|-----------|:---:|:----:|:----:|:--------------------:|:---:|
| USC-SIPI (8 imgs) | 0.563 | 33.2 | 0.961 | 0.48 | 0.62 |
| Kodak (24 imgs) | 0.558 | 34.1 | 0.968 | 0.41 | 0.59 |
| McMaster (18 imgs) | 0.554 | 33.8 | 0.965 | 0.39 | 0.57 |

BD (brightness difference) is lower than all compared methods [14], [22], [25].
